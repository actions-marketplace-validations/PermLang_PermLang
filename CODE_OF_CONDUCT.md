# Code of conduct

PermLang follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
in everything the project does: issues, discussions, pull requests, reviews, and
anywhere else someone acts for the project.

In short: be respectful and welcoming, criticise ideas rather than people, and
accept that others may see things differently. Harassment, insults, sexualised
language or imagery, and publishing someone's private information aren't
acceptable, from anyone.

## Reporting

Report anything that breaks this code to the maintainer, Aaron, at
**aaron@park-web.com**. Reports are read only by the maintainers, kept
confidential, and answered within a week. If a report concerns a maintainer,
say so, and it will be handled by someone else the reporter agrees to.

A security problem isn't a conduct report: report it privately as
[SECURITY.md](SECURITY.md) describes.

## What happens

The maintainers look into each report and act in proportion to what happened,
following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
a private correction, a warning, a temporary ban, or a permanent ban. They tell
the person who reported it what was done.
